Cálculo integral

A derivada parte de uma quantidade e encontra sua taxa de variação. A integral faz o caminho de volta: soma pequenas taxas para reconstruir o total acumulado, como distância, área, volume ou probabilidade.

Conceito e interpretações

A integral de uma função \(f(x)\) é, em essência, o processo inverso da derivação. Encontramos uma função \(F(x)\) cuja derivada é \(f(x)\).

\[ \int f(x)\,dx = F(x) + C \]
  • \(\int f(x)\,dx\): integral (indefinida);
  • \(F(x)\): primitiva de \(f(x)\);
  • \(C\): constante de integração.

Interpretações

  • Geométrica: cálculo de áreas.
  • Física: deslocamento, trabalho, centro de massa.
  • Econômica: acumulação (custo, receita, lucro).
  • Probabilidade: funções de distribuição.
  • É uma família de funções (infinitas primitivas).

Se \(F'(x) = f(x)\), então \(F(x)\) é uma primitiva (ou antiderivada) de \(f(x)\).

Propriedades da integral indefinida

  • Linearidade: \[ \begin{aligned} &\int [a f(x) + b g(x)]\,dx \\ &= a\int f(x)\,dx + b\int g(x)\,dx \end{aligned} \]
  • Constante de integração: se \(F'(x) = f(x)\), então \(\int f(x)\,dx = F(x) + C\), com \(C \in \mathbb{R}\).
  • Unicidade: se \(F\) e \(G\) são primitivas de \(f\), então \(F(x) = G(x) + C\).
  • Integral da derivada: \[ \int F'(x)\,dx = F(x) + C. \]
  • Derivada da integral: \[ \frac{d}{dx}\left[\int f(x)\,dx\right] = f(x). \]

A integral desfaz a derivada (até uma constante).

\(\csc x \cdot \operatorname{cotg} x\) \(-\csc x + C\)

Exemplo resolvido: \(\displaystyle\int \left(4x^3 - \frac{2}{x} + e^x\right) dx\)

Ver solução
  1. Integre termo a termo: \(4 \cdot \frac{x^4}{4} - 2\ln|x| + e^x\).
  2. Resultado: \(x^4 - 2\ln|x| + e^x + C\).
  3. Conferência: \((x^4 - 2\ln|x| + e^x)' = 4x^3 - \frac{2}{x} + e^x\). Confere.

Regras de integração

Substituição (mudança de variável)

Se \(u = g(x)\), \(du = g'(x)\,dx\):

\[ \int f(g(x)) \cdot g'(x)\,dx = \int f(u)\,du \]

Por partes

\[ \int u\,dv = uv - \int v\,du \]

Escolha bem \(u\) e \(dv\)!

Frações parciais

Decompõe uma fração racional em soma de frações mais simples.

Substituições trigonométricas

Usadas para expressões com \(\sqrt{a^2 - x^2}\), \(\sqrt{a^2 + x^2}\) e \(\sqrt{x^2 - a^2}\).

Integrais trigonométricas

Usa identidades trigonométricas para simplificar a integral.

Integração por substituição

  1. Escolha \(u = g(x)\).
  2. Calcule \(du = g'(x)\,dx\).
  3. Substitua na integral.
  4. Resolva e volte para a variável \(x\).

Exemplo

\(\displaystyle\int 2x \cos(x^2)\,dx\), com \(u = x^2\) e \(du = 2x\,dx\):

\[ \begin{aligned} \int 2x\cos(x^2)\,dx &= \int \cos(u)\,du \\ &= \operatorname{sen}(u) + C \\ &= \operatorname{sen}(x^2) + C \end{aligned} \]

Simplifica a integral!

Exemplo resolvido: \(\displaystyle\int x \cos(x^2)\,dx\)

Ver solução
  1. Escolha \(u = x^2\). Então \(du = 2x\,dx\), ou seja, \(x\,dx = \frac{du}{2}\).
  2. \(\int \cos u \cdot \frac{du}{2} = \frac{1}{2}\operatorname{sen} u + C\).
  3. Volte para \(x\): \(\frac{1}{2}\operatorname{sen}(x^2) + C\).

Integração por partes

\[ \int u\,dv = uv - \int v\,du \]
  1. Escolha \(u\) e \(dv\).
  2. Calcule \(du\) e \(v\).
  3. Aplique a fórmula.

Útil quando há produto de funções (como polinômio × trigonométrica, exponencial, etc.).

Exemplo

\(\displaystyle\int x e^x\,dx\), com \(u = x \Rightarrow du = dx\) e \(dv = e^x\,dx \Rightarrow v = e^x\):

\[ \begin{aligned} \int x e^x\,dx &= x e^x - \int e^x\,dx \\ &= x e^x - e^x + C \\ &= e^x(x - 1) + C \end{aligned} \]

Exemplo resolvido: \(\displaystyle\int x \operatorname{sen} x\,dx\)

Ver solução
  1. \(u = x\) e \(dv = \operatorname{sen} x\,dx\).
  2. Então \(du = dx\) e \(v = -\cos x\).
  3. \(\int x \operatorname{sen} x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \operatorname{sen} x + C\).

Exemplo resolvido: \(\displaystyle\int \ln x\,dx\)

Ver solução
  1. \(u = \ln x\) e \(dv = dx\). Então \(du = \frac{1}{x}dx\) e \(v = x\).
  2. \(x \ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - x + C\).

Frações parciais

Usada para integrar funções racionais:

\[ \int \frac{P(x)}{Q(x)}\,dx, \]

onde \(P\) e \(Q\) são polinômios.

Passos

  1. Fatorar o denominador \(Q(x)\).
  2. Decompor em frações simples.
  3. Determinar os coeficientes.
  4. Integrar termo a termo.

Exemplo

\[ \begin{aligned} &\int \frac{2x+3}{x^2-1}\,dx \\ &= \int \frac{2x+3}{(x-1)(x+1)}\,dx \end{aligned} \]

Decomponha:

\[ \frac{2x+3}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1} \]

Então \(2x + 3 = A(x+1) + B(x-1)\). Com \(x = 1\): \(5 = 2A\), logo \(A = \frac{5}{2}\). Com \(x = -1\): \(1 = -2B\), logo \(B = -\frac{1}{2}\). Assim:

\[ \begin{aligned} &\int \frac{2x+3}{x^2-1}\,dx \\ &= \int \frac{A}{x-1}\,dx + \int \frac{B}{x+1}\,dx \\ &= A\ln|x-1| + B\ln|x+1| + C \\ &= \tfrac{5}{2}\ln|x-1| - \tfrac{1}{2}\ln|x+1| + C \end{aligned} \]

Substituições trigonométricas

Usadas para integrais com raízes quadradas:

1 - \(\sqrt{a^2 - x^2}\)

\[ x = a\operatorname{sen}\theta, \quad dx = a\cos\theta\,d\theta \]

\((-a \le x \le a)\)

2 - \(\sqrt{a^2 + x^2}\)

\[ x = a\operatorname{tg}\theta, \quad dx = a\sec^2\theta\,d\theta \]

\((x \in \mathbb{R})\)

3 - \(\sqrt{x^2 - a^2}\)

\[ x = a\sec\theta, \quad dx = a\sec\theta\operatorname{tg}\theta\,d\theta \]

\((|x| \ge a)\)

Essas substituições transformam a raiz em expressões trigonométricas mais simples!

Integral Resultado
\(\int \operatorname{sen} x\,dx\) \(-\cos x + C\)
\(\int \cos x\,dx\) \(\operatorname{sen} x + C\)
\(\int \operatorname{tg} x\,dx\) \(-\ln|\cos x| + C\)
\(\int \operatorname{cotg} x\,dx\) \(\ln|\operatorname{sen} x| + C\)
\(\int \sec x\,dx\) \(\ln|\sec x + \operatorname{tg} x| + C\)
\(\int \csc x\,dx\) \(\ln|\csc x - \operatorname{cotg} x| + C\)
\(\int \sec^2 x\,dx\) \(\operatorname{tg} x + C\)
\(\int \csc^2 x\,dx\) \(-\operatorname{cotg} x + C\)

\(\int \csc x \cdot \operatorname{cotg} x\,dx\) \(-\csc x + C\)

Muitas vezes, usamos identidades para simplificar a integral!

Identidades úteis

  • \(\operatorname{sen}^2 x + \cos^2 x = 1\)
  • \(1 + \operatorname{tg}^2 x = \sec^2 x\)
  • \(1 + \operatorname{cotg}^2 x = \csc^2 x\)
  • \(\operatorname{sen}(2x) = 2\operatorname{sen} x \cos x\)
  • \(\cos(2x) = \cos^2 x - \operatorname{sen}^2 x\)

Integrais definidas e Teorema Fundamental

Integral definida

\(\displaystyle\int_a^b f(x)\,dx\) = área algébrica sob o gráfico de \(f\) no intervalo \([a, b]\).

Teorema Fundamental do Cálculo

Se \(f\) é contínua em \([a, b]\) e \(F\) é uma primitiva de \(f\), então

\[ \int_a^b f(x)\,dx = F(b) - F(a). \]

Conecta derivada e integral!

Exemplo resolvido: a área do gráfico interativo

Calcule \(\displaystyle\int_0^3 \left(\frac{x^2}{3} + \frac{1}{2}\right) dx\).

Ver solução
  1. Primitiva: \(F(x) = \frac{x^3}{9} + \frac{x}{2}\).
  2. \(F(3) = \frac{27}{9} + \frac{3}{2} = 3 + 1{,}5 = 4{,}5\).
  3. \(F(0) = 0\). Logo, a integral vale \(4{,}5\), o mesmo valor para o qual os retângulos convergem.

Aplicações da integral definida

  • Cálculo de áreas entre curvas.
  • Volumes de sólidos de revolução.
  • Comprimento de arco.
  • Trabalho realizado por uma força.
  • Centro de massa e momentos.
  • Probabilidades e estatística.
  • Economia (custo, receita, excedente).
  • Física (velocidade → deslocamento, aceleração → velocidade).

Integrais estão em toda parte!

Na computação: integração numérica num game loop

Um motor de jogo não calcula a integral exata da aceleração e da velocidade. A cada quadro (frame), ele soma um pequeno retângulo de largura \(\Delta t\), a mesma ideia das somas de Riemann. 

GRAVIDADE = -9.8
dt = 1 / 60                 # 60 quadros por segundo

def atualizar(obj):
    obj.vel += GRAVIDADE * dt    # integra a aceleração
    obj.pos += obj.vel * dt      # integra a velocidade

Esse é o método de Euler. Quanto menor o \(\Delta t\), mais perto do valor exato, como acontece com os retângulos quando \(n\) aumenta.

Dicas finais

  • Pratique bastante: a técnica vem com exercícios!
  • Identifique o tipo de integral antes de escolher o método.
  • Use identidades trigonométricas para simplificar.
  • Não esqueça a constante de integração (+ C).
  • Verifique o resultado derivando!
