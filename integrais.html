Cálculo integral

A derivada parte de uma quantidade e encontra sua taxa de variação. A integral faz o caminho de volta: soma pequenas taxas para reconstruir o total acumulado, como distância, área, volume ou probabilidade.

Antiderivadas e integral indefinida

Uma antiderivada (ou primitiva) de \(f\) é uma função \(F\) cuja derivada é \(f\). Por exemplo, \(F(x) = x^3\) é primitiva de \(f(x) = 3x^2\). Mas \(x^3 + 5\) também é, porque a derivada de uma constante é zero.

Integral indefinida

\[ \int f(x)\,dx = F(x) + C, \quad \text{onde } F'(x) = f(x). \]

A constante \(C\) representa toda a família de primitivas. Para conferir uma integral, derive o resultado: você deve voltar ao integrando.

FunçãoIntegral
\(x^n\), com \(n \ne -1\)\(\dfrac{x^{n+1}}{n+1} + C\)
\(\dfrac{1}{x}\)\(\ln|x| + C\)
\(e^x\)\(e^x + C\)
\(a^x\)\(\dfrac{a^x}{\ln a} + C\)
\(\operatorname{sen} x\)\(-\cos x + C\)
\(\cos x\)\(\operatorname{sen} x + C\)
\(\sec^2 x\)\(\tan x + C\)

A integral é linear: \(\int (af + bg)\,dx = a\int f\,dx + b\int g\,dx\).

Exemplo resolvido: \(\displaystyle\int \left(4x^3 - \frac{2}{x} + e^x\right) dx\)

Ver solução
  1. Integre termo a termo: \(4 \cdot \frac{x^4}{4} - 2\ln|x| + e^x\).
  2. Resultado: \(x^4 - 2\ln|x| + e^x + C\).
  3. Conferência: \((x^4 - 2\ln|x| + e^x)' = 4x^3 - \frac{2}{x} + e^x\). Confere.

Integral definida e área

Como medir a área sob uma curva? A ideia de Riemann é cobrir a região com \(n\) retângulos finos, somar as áreas deles e então fazer \(n\) crescer.

Definição

\[ \int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x, \qquad \Delta x = \frac{b - a}{n}. \]

Quando \(f \ge 0\), o resultado é a área entre o gráfico e o eixo \(x\), de \(a\) até \(b\). Partes abaixo do eixo contam com sinal negativo.

Propriedades úteis: \(\int_a^a f = 0\), \(\int_b^a f = -\int_a^b f\) e \(\int_a^b f + \int_b^c f = \int_a^c f\).

Teorema Fundamental do Cálculo

Calcular limites de somas toda vez seria trabalhoso. O Teorema Fundamental liga as duas metades da disciplina e mostra que integrar é desfazer a derivada.

Teorema Fundamental do Cálculo

Parte 1. Se \(f\) é contínua, então \(\displaystyle\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\).

Parte 2. Se \(F\) é qualquer primitiva de \(f\) em \([a, b]\), então

\[ \int_a^b f(x)\,dx = F(b) - F(a) = \Big[F(x)\Big]_a^b. \]

Exemplo resolvido: a área do gráfico interativo

Calcule \(\displaystyle\int_0^3 \left(\frac{x^2}{3} + \frac{1}{2}\right) dx\).

Ver solução
  1. Primitiva: \(F(x) = \frac{x^3}{9} + \frac{x}{2}\).
  2. \(F(3) = \frac{27}{9} + \frac{3}{2} = 3 + 1{,}5 = 4{,}5\).
  3. \(F(0) = 0\). Logo, a integral vale \(4{,}5\), o mesmo valor para o qual os retângulos convergem.

Integração por substituição

É a regra da cadeia ao contrário. Procure uma função "de dentro" \(u = g(x)\) cuja derivada também apareça no integrando:

\[ \int f(g(x))\,g'(x)\,dx = \int f(u)\,du, \qquad u = g(x),\ du = g'(x)\,dx. \]

Exemplo resolvido: \(\displaystyle\int x \cos(x^2)\,dx\)

Ver solução
  1. Escolha \(u = x^2\). Então \(du = 2x\,dx\), ou seja, \(x\,dx = \frac{du}{2}\).
  2. \(\int \cos u \cdot \frac{du}{2} = \frac{1}{2}\operatorname{sen} u + C\).
  3. Volte para \(x\): \(\frac{1}{2}\operatorname{sen}(x^2) + C\).

Em integrais definidas, troque também os limites: se \(x\) vai de \(a\) a \(b\), então \(u\) vai de \(g(a)\) a \(g(b)\).

Integração por partes

É a regra do produto ao contrário. Serve para integrais de produtos como \(x e^x\), \(x \operatorname{sen} x\) ou \(\ln x\):

\[ \int u\,dv = uv - \int v\,du. \]

Para escolher \(u\), use a ordem LIATE: Logarítmica, Inversa trigonométrica, Algébrica, Trigonométrica, Exponencial. A que aparecer primeiro nessa lista costuma ser a melhor escolha para \(u\).

Exemplo resolvido: \(\displaystyle\int x \operatorname{sen} x\,dx\)

Ver solução
  1. Pela LIATE, \(u = x\) (algébrica) e \(dv = \operatorname{sen} x\,dx\).
  2. Então \(du = dx\) e \(v = -\cos x\).
  3. \(\int x \operatorname{sen} x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \operatorname{sen} x + C\).

Exemplo resolvido: \(\displaystyle\int \ln x\,dx\)

Ver solução
  1. \(u = \ln x\) e \(dv = dx\). Então \(du = \frac{1}{x}dx\) e \(v = x\).
  2. \(x \ln x - \int x \cdot \frac{1}{x}\,dx = x\ln x - x + C\).

Aplicações

Volumes de sólidos de revolução

Girando o gráfico de \(f\) em torno do eixo \(x\), cada fatia vira um disco de raio \(f(x)\). Somando os discos:

\[ V = \pi \int_a^b [f(x)]^2\,dx. \]

Exemplo: girando \(y = r\), de \(0\) a \(h\), obtemos um cilindro, e \(V = \pi \int_0^h r^2\,dx = \pi r^2 h\), a fórmula conhecida.

Probabilidade em ciência de dados

Para uma variável contínua com função densidade \(f\), a probabilidade de cair num intervalo é a área sob a densidade:

\[ P(a \le X \le b) = \int_a^b f(x)\,dx, \qquad \int_{-\infty}^{\infty} f(x)\,dx = 1. \]

A curva normal, base de testes estatísticos e de muitos modelos de machine learning, é usada exatamente assim.

Simulações físicas e motores de jogos

Velocidade é a integral da aceleração, e posição é a integral da velocidade. Um motor de jogo não resolve essas integrais de forma exata. Ele aproxima a cada quadro (frame), somando pequenos retângulos de largura \(\Delta t\), a mesma ideia das somas de Riemann.

Integração numérica num game loop

GRAVIDADE = -9.8
dt = 1 / 60                 # 60 quadros por segundo

def atualizar(obj):
    obj.vel += GRAVIDADE * dt    # integra a aceleração
    obj.pos += obj.vel * dt      # integra a velocidade

Esse é o método de Euler. Quanto menor o \(\Delta t\), mais perto do valor exato, como acontece com os retângulos quando \(n\) aumenta.
