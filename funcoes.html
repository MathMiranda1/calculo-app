Bloco 1

Funções reais e modelagem

Antes de falar em limites ou derivadas, é preciso saber descrever uma relação entre duas grandezas. Uma função é essa descrição: dada uma entrada, ela devolve exatamente uma saída.

Conceito de função

Pense numa função como um programa que recebe um número e devolve outro. A regra é sempre a mesma, e para cada entrada existe uma única saída.

Definição

Uma função \(f: A \to B\) associa a cada elemento \(x\) do conjunto \(A\) um único elemento \(y = f(x)\) do conjunto \(B\).

  • Domínio \(D(f) = A\): todas as entradas permitidas.
  • Contradomínio \(B\): onde as saídas podem cair.
  • Imagem \(\operatorname{Im}(f)\): as saídas que de fato aparecem. Sempre \(\operatorname{Im}(f) \subseteq B\).

Quando o domínio não é informado, ele é o maior conjunto de números reais onde a fórmula faz sentido. Na prática, três situações restringem o domínio:

  • divisão por zero: o denominador precisa ser diferente de zero;
  • raiz de índice par: o radicando precisa ser maior ou igual a zero;
  • logaritmo: o argumento precisa ser estritamente positivo.

Exemplo resolvido: encontre o domínio de \(f(x) = \dfrac{\sqrt{x}}{x - 2}\)

Ver solução
  1. A raiz exige \(x \ge 0\).
  2. O denominador exige \(x - 2 \ne 0\), ou seja, \(x \ne 2\).
  3. As duas condições juntas: \(D(f) = \{x \in \mathbb{R} \mid x \ge 0 \text{ e } x \ne 2\} = [0, 2) \cup (2, +\infty)\).

Construção de gráficos

O gráfico de \(f\) é o conjunto de pontos \((x, f(x))\) no plano. Para esboçar à mão: monte uma tabela com alguns valores de \(x\), calcule \(f(x)\), marque os pontos e ligue respeitando o domínio. O teste da reta vertical confirma se uma curva é função: nenhuma reta vertical pode cortá-la em mais de um ponto.

Funções elementares

Quase todo modelo que você vai encontrar é construído a partir de cinco famílias. Escolha uma família abaixo e mexa nos parâmetros para ver como cada um muda o gráfico.

Funções de 1º e 2º graus

1º grau: \(f(x) = ax + b\)

O gráfico é uma reta. O coeficiente \(a\) é a taxa de variação: quanto \(f\) muda quando \(x\) aumenta 1. Se \(a \gt 0\) a reta sobe; se \(a \lt 0\), desce. O coeficiente \(b\) é onde a reta corta o eixo \(y\), e a raiz é \(x = -\frac{b}{a}\).

2º grau: \(f(x) = ax^2 + bx + c\)

O gráfico é uma parábola, com concavidade para cima se \(a \gt 0\) e para baixo se \(a \lt 0\). As raízes vêm da fórmula de Bhaskara, e o vértice marca o ponto de máximo ou de mínimo:

\[ x = \frac{-b \pm \sqrt{\Delta}}{2a}, \quad \Delta = b^2 - 4ac \qquad\qquad V = \left(-\frac{b}{2a},\ -\frac{\Delta}{4a}\right) \]

Exemplo resolvido: analise \(f(x) = -x^2 + 4x + 5\)

Ver solução
  1. \(a = -1 \lt 0\): concavidade para baixo, então o vértice é um máximo.
  2. \(\Delta = 16 + 20 = 36\). Raízes: \(x = \frac{-4 \pm 6}{-2}\), ou seja, \(x = -1\) e \(x = 5\).
  3. Vértice: \(x_v = -\frac{4}{-2} = 2\) e \(f(2) = -4 + 8 + 5 = 9\). Ponto máximo \((2, 9)\).
  4. Imagem: \((-\infty, 9]\).

Exponencial e logaritmo

Na exponencial \(f(x) = b^x\), com \(b \gt 0\) e \(b \ne 1\), a variável está no expoente. Cada vez que \(x\) aumenta 1, o valor é multiplicado por \(b\). Por isso ela cresce muito rápido quando \(b \gt 1\). A base mais importante do Cálculo é \(e \approx 2{,}71828\).

O logaritmo é a operação inversa: \(\log_b y = x\) significa \(b^x = y\). Ele responde à pergunta "a que potência devo elevar \(b\) para obter \(y\)?". Seu domínio são os reais positivos, e ele cresce muito devagar.

PropriedadeExponencialLogaritmo
Produto\(b^m \cdot b^n = b^{m+n}\)\(\log(xy) = \log x + \log y\)
Quociente\(b^m / b^n = b^{m-n}\)\(\log(x/y) = \log x - \log y\)
Potência\((b^m)^n = b^{mn}\)\(\log x^n = n \log x\)
Mudança de base\(b^x = e^{x \ln b}\)\(\log_b x = \frac{\ln x}{\ln b}\)

Na computação

Uma senha de 8 caracteres com 62 símbolos possíveis tem \(62^8 \approx 2{,}2 \times 10^{14}\) combinações. Cada caractere a mais multiplica esse número por 62. Esse crescimento exponencial é o que torna a força bruta inviável.

O logaritmo aparece no sentido oposto. A busca binária corta a lista ao meio a cada passo, então encontra um item entre 1 milhão em cerca de \(\log_2 10^6 \approx 20\) comparações.

Funções trigonométricas

Seno e cosseno descrevem fenômenos que se repetem. No círculo de raio 1, um ângulo \(x\) (em radianos) determina o ponto \((\cos x, \operatorname{sen} x)\). As duas funções têm imagem \([-1, 1]\) e período \(2\pi\).

Em \(f(x) = a \operatorname{sen}(bx)\), \(|a|\) é a amplitude e \(\frac{2\pi}{b}\) é o período. A tangente, \(\tan x = \frac{\operatorname{sen} x}{\cos x}\), não está definida onde \(\cos x = 0\).

Identidade fundamental: \(\operatorname{sen}^2 x + \cos^2 x = 1\).

Modelagem de problemas

Modelar é traduzir uma situação real para uma função. O roteiro é sempre parecido:

  1. identificar a variável de entrada e a de saída, com unidades;
  2. observar o padrão: soma fixa por passo sugere 1º grau, multiplicação fixa por passo sugere exponencial;
  3. usar dados conhecidos para achar os parâmetros;
  4. testar o modelo com um valor que você já conhece.

Exemplo resolvido: custo de servidor ou crescimento de dados

Um serviço paga R$ 200 fixos por mês mais R$ 0,05 por requisição. Os dados armazenados começam em 50 GB e crescem 10% ao mês. Escreva os dois modelos.

Ver solução
  1. Custo: soma-se um valor fixo a cada requisição, então é 1º grau. \(C(n) = 0{,}05n + 200\). Com 10 mil requisições: \(C = 700\) reais.
  2. Dados: multiplica-se por 1,1 a cada mês, então é exponencial. \(D(t) = 50 \cdot 1{,}1^t\).
  3. Quando os dados passam de 100 GB? \(1{,}1^t = 2 \Rightarrow t = \frac{\ln 2}{\ln 1{,}1} \approx 7{,}3\). Isso acontece no 8º mês.

Escalabilidade de código

O tempo de execução de um algoritmo é uma função do tamanho da entrada \(n\). Um laço simples custa algo como \(T(n) = an + b\). Dois laços aninhados custam \(T(n) = an^2 + bn + c\).

for i in range(n):        # n vezes
    for j in range(n):    # n vezes para cada i
        processa(i, j)    # total: n² operações

Dobrar \(n\) dobra o tempo no primeiro caso e quadruplica no segundo. O bloco 2 mostra como os limites formalizam essa comparação.
