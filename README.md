# Tangente: Cálculo Diferencial e Integral

Site de estudo com teoria, exemplos resolvidos, gráficos interativos e exercícios dos quatro blocos da disciplina.

## Como abrir

Dê dois cliques em `index.html`. Precisa de internet para carregar as fontes e as fórmulas (KaTeX).

## Estrutura

```
index.html        página inicial e progresso
funcoes.html      Bloco 1: funções reais e modelagem
limites.html      Bloco 2: limites e continuidade
derivadas.html    Bloco 3: cálculo diferencial
integrais.html    Bloco 4: cálculo integral
quiz.html         quiz com questões sorteadas
css/style.css     visual de todas as páginas
js/questoes.js    banco de questões (edite aqui para adicionar)
js/graficos.js    desenho dos gráficos em SVG
js/demos.js       gráficos interativos de cada página
js/app.js         fórmulas, exercícios, progresso e quiz
```

## Adicionar uma questão

Copie um objeto em `js/questoes.js`, troque o `id` por um novo e edite o texto. `correta` é a posição da alternativa certa, começando em 0.
